# X17THOSDebloat
Xiaomi 17T HyperOS Debloat (ADB) - Kumpulan daftar paket dan script untuk menonaktifkan aplikasi sistem yang tidak dibutuhkan di **Xiaomi 17T (HyperOS 3.0.304)** lewat **ADB dari PC**, tanpa root dan bisa dibalikkan.  Reversible, root-free ADB debloat lists and helper scripts for the Xiaomi 17T on HyperOS 3.
